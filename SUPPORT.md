# Support

Thanks for using Ascended Core! Here is where to get help.

## Getting help

- **Questions & ideas:** use [GitHub Discussions](https://github.com/third-eye-cyborg/ascended-core/discussions)
  for how-to questions, design discussion, and sharing what you're building.
- **Bug reports:** open an issue using the **Bug report** template.
- **Feature requests:** open an issue using the **Feature request** template.
- **New provider ports/adapters:** open an issue using the **Provider request**
  template.
- **Documentation issues:** open an issue using the **Docs** template.

Before opening a new issue, please search existing issues and discussions to
avoid duplicates.

## Security

Do not report security issues in public. Follow the private reporting process
in [SECURITY.md](./SECURITY.md).

## What is in scope

- The `@third-eye-cyborg/*` packages published from this repository.
- The reference examples in `examples/`.
- Documentation in `docs/`.

## What is out of scope

- **Downstream product support.** Ascended Core is vendor-neutral
  infrastructure. Support for products built on top of Core — including the
  private downstream product — is handled by those product teams, not here.
- **Vendor-specific production integrations.** Core ships vendor-neutral ports
  and generic in-memory adapters only. Building and operating real vendor
  integrations is the responsibility of downstream consumers.
- **Consulting or bespoke implementation work.**

If you're not sure whether your question is in scope, start a Discussion and the
maintainers will point you in the right direction.
